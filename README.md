# Connect 4 vs Neural Network

A Connect 4 game where you play against a computer opponent powered by an artificial neural network (ANN). The network is trained with self-play in Python (PyTorch), then runs directly in your browser, so the game needs no server.

**Live demo:** _add your link here after deploying (see [Deploy](#deploy-to-github-pages))_

## Features

- Play in the browser with a canvas-drawn board and animated falling discs
- Three difficulty levels (Easy, Medium, Hard)
- Choose whether to move first or second
- Undo, hint (a green arrow over the suggested column), and sound on/off
- A win bar showing the network's own estimate of your winning chances
- Scoreboard saved in your browser
- Keyboard controls: `1`-`7` to drop a disc, `U` to undo, `H` for a hint
- Works on desktop and mobile

## How it works

1. **Network.** A small neural network takes the board as 84 numbers (your discs and your opponent's discs, seen from the side to move) and outputs a score from -1 (losing) to +1 (winning).
2. **Training.** The network plays games against itself. Every position is labelled with the final result, and the network learns to predict it. Training also uses mirrored boards and a replay buffer, and only saves a new model if it beats the previous best.
3. **Search.** To choose a move, the game looks several moves ahead with negamax and alpha-beta pruning, using the network to score the positions it reaches. Difficulty sets how many moves ahead it looks.
4. **Browser.** The trained weights are exported to `weights.js`, and `index.html` runs the same network and search in JavaScript.

## Project structure

| File | Purpose |
| --- | --- |
| `index.html` | The game (graphics, controls, search, and the network in JavaScript) |
| `weights.js` | Trained network weights, generated by `export_weights.py` |
| `connect4_ann.py` | Game rules, network, search and basic training in Python (also playable in the terminal) |
| `train_v2.py` | Stronger training: mirror augmentation, deeper self-play, and a gate that keeps only improving models |
| `export_weights.py` | Converts `connect4_ann.pt` into `weights.js` |

If `weights.js` is missing, the game still runs using a simple built-in evaluation, but it will be much weaker.

## Quick start

To play locally, put `index.html` and `weights.js` in the same folder and open `index.html` in a browser.

## Train your own model

You need Python 3.9+ and PyTorch:

```bash
pip install torch numpy
```

Train (this continues from `connect4_ann.pt` if it exists):

```bash
python train_v2.py 100 20
```

The two numbers are iterations and games per iteration. Every 10 iterations it prints a score against a random player and against the previous best model, and it only saves the model when it wins at least half of the games against the previous best. Run the command again to keep training.

Then export the weights for the website:

```bash
python export_weights.py
```

This creates `weights.js`. Replace the old one next to `index.html`.

### Training on Google Colab

Training on a CPU is slow, so Colab is a convenient option:

1. Upload `connect4_ann.py`, `train_v2.py` and `export_weights.py` in the Files panel.
2. Run `!python train_v2.py 100 20`
3. Run `!python export_weights.py`
4. Download `weights.js` (and `connect4_ann.pt` if you want to continue training later), since Colab files are deleted when the session ends.

### Play in the terminal

```bash
python connect4_ann.py play
```

Enter a column number from 1 to 7.

## Deploy to GitHub Pages

1. Create a GitHub repository and upload all the files, including `weights.js`.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, select your main branch and the `/ (root)` folder, then save.
4. After a minute, your game is live at `https://<your-username>.github.io/<repository-name>/`.

The game is plain HTML and JavaScript, so it also works on any static host such as Netlify or Vercel.
